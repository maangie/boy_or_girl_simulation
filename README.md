# 男の子が生まれるまで子供を作り続ける国のシミュレーション

## 問題

ある国では、生まれてくる子に男の子だけを欲しがりました。
そのため、どの家族も男の子を産むまで子供を作り続けました。
この国では男の子と女の子の人口比率はどうなりますか？

## 理論上の答え

**男女比は 1:1（50:50）になる。**

各出産で男女の確率は常に 50% であり、「いつ止めるか」という戦略は全体の男女比に影響しない。

## 実行方法

```bash
python boy_or_girl_simulation.py
```

## 出力

- コンソールに各試行の男の子数・女の子数・比率を表示
- `result.png` に以下の 3 つのグラフを保存
  - **(a) 棒グラフ**: 各試行の男女数
  - **(b) 折れ線グラフ**: 累積男児比率の収束（理論値 50% との比較）
  - **(c) ヒストグラム**: 家族ごとの子供数の分布（幾何分布）
